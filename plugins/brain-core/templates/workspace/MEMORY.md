# MEMORY

The single learning store. **Newest entries at the top**, under a dated heading. One line per
learning: what happened, what it means, and (when it should change behaviour) the rule it
suggests. A pattern that fires 3 times across distinct sessions is a candidate for `RULES.md`;
{{OWNER_FIRST_NAME}} decides.

Format:

```
## YYYY-MM-DD
- **<area>**: <what was learned>. <why it matters / what to do differently>.
```
