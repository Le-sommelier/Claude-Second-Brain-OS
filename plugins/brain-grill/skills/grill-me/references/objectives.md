# Mode: objectives

Grill a set of objectives (personal, or for a team) until each one is specific, evidenced and honest.

**Confidential by default.** Objectives, reviews and growth notes live in the confidential area of the
workspace. In this mode:

- Do not run `gather_context.py` and do not query the project index. Read only the file or text the owner points to,
  and, if the owner asks for it, material under the confidential folders.
- Never append anything to a project, never write the holes into a shared surface.
- The holes list stays in chat. If the owner wants it saved, ask where: it may only go into a file inside the
  confidential area, and you mark it `sensitivity: confidential`. `holes_payload.py` refuses this mode on purpose.

## Branches to walk

1. **Count and focus.** How many objectives, and can the owner name the one that matters most? More than four
   usually means none is protected.
2. **Outcome versus activity.** For each, is it a result ("reduce checkout drop-off") or a task ("run workshops")?
   What changes in the world if it is achieved?
3. **Measurability.** What is the measure, the baseline, the target, the date, and the source of truth? Who else
   can verify it?
4. **Stretch and honesty.** What is the chance of achieving it as written? What would a 70 percent outcome look
   like? Is it a stretch or a sandbag?
5. **Control.** What depends on other people or teams? What does the owner do when they do not deliver?
6. **Alignment.** Which team or company goal does each serve? Would the manager recognise the link and agree on
   the priority?
7. **Evidence trail.** What will the owner be able to show at the end, and is it being collected as the work goes?
8. **Growth.** Which objective stretches a skill the owner wants to build, and is that stated?
9. **Trade-offs.** What will the owner stop doing to make room? If nothing, the list is a wish list.

## Questions that tend to break an objective

- "Imagine the period ended. What would a sceptical colleague point at to say you did it?"
- "Which of these would you still pursue if nobody reviewed it?"
- "What is on this list because it sounds right to your manager?"

## Where holes go

In chat first. Saved only with the owner's say-so into a confidential file, never into a project.
