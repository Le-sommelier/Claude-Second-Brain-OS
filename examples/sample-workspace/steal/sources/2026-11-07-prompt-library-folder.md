# Keep a prompt library as plain files, one per recurring task

> Source: @devon.example, an invented thread for the sample workspace, 2026-11-07.

Paraphrased summary: a thread arguing that every prompt you paste more than twice belongs in a small markdown
file with a name, a purpose line and an example output. The author keeps forty of them in one folder and reuses
them from the command line. No evidence beyond the author's own folder listing; the thread ends with a request
to subscribe to a newsletter.

Ideas worth separating:

1. One file per recurring prompt, with a purpose line and one example output.
2. Retire a prompt when its output stops being edited by hand.
